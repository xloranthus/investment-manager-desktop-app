# Investment Manager Desktop App

* Manage securities (bonds, stocks, funds, ETFs) in your portfolio, and keep track of their:
  * ISIN
  * Name
  * Quantity
  * Average purchase price
  * Current market Price
  * Market value
  * Unrealized profit & loss
  * Return percentage

* Add newly bought securities by providing their:
  * ISIN code (unique identifier)
  * Name
  * Purchased quantity
  * Purchase price in the security's base currency

* Re-buy or sell securities already in your portfolio comfortably by chosing the ISIN code from a dropdown list (name and base currency will be filled automatically) and providing the quantity and purchase/sell price.

* Prices and values can be displayed in 3 different currencies:
  * HUF
  * EUR
  * USD

* You can manually update the market price of securities in the portfolio and the exchange rate of supported currency pairs.

* The app automatically calculates average purchase price, market value, unrealized profit & loss and return percentage.

* You can save the portfolio and exchange rate settings to the hard drive and load it later. An example portfolio file can be found in the root folder: `example.portfolio`. This file simulates a portfolio where the securities were bought on 27th May 2025. The market prices were then updated to the current prices as of 27th May 2026.
